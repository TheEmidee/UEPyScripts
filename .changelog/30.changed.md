Reworked the UGS bucket layout to be content-addressed: every file is stored once as a zstd-compressed blob keyed by its hash, and each published commit only writes a manifest. UGS.pull downloads just the files that differ from the previous sync (no more deltas, checkpoints or 7-Zip), and switching branches only fetches what changed. Existing buckets must be emptied before the first push with this version.
